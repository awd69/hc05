# 给队友：怎么把这套蓝牙代码接进你自己的工程

你用的是 **CubeMX + Keil**，我这里用的是 EIDE，但没关系 —— **你只需要这两个文件**：

```
hc05.c
hc05.h
```

其它东西（HAL 库、启动文件、链接脚本）都用你自己工程里的，不用管我这边。

---

## 第一步：CubeMX 里检查 3 项

| 检查什么 | 应该是什么 |
|---|---|
| USART1 模式 | **Asynchronous (异步)** |
| 波特率 | **9600** |
| 字长/校验/停止位 | 8 位 / 无 / 1 位 |
| 引脚 | **PA9 = USART1_TX**，**PA10 = USART1_RX** |

**最重要的一项（很多人栽在这）：**

> 左边 `Connectivity → USART1 → NVIC Settings` 标签页里，
> 把 **USART1 global interrupt** 前面的**勾打上**。
>
> 不勾的话，串口永远收不到数据，代码层面查半天也查不出来。

改完点 **GENERATE CODE**。

---

## 第二步：Keil 里把文件加进去

1. `hc05.c` 复制到你的 `Core/Src/` 目录
2. `hc05.h` 复制到你的 `Core/Inc/` 目录
3. Keil 左边工程树 → 找到放着 `main.c` 的那个组（一般叫 `Application/User/Core`）→ **右键 → Add Existing Files to Group...** → 选 `hc05.c` → Add
4. 菜单 `Project → Options for Target → C/C++` 标签页 → `Include Paths` 里确认有 `..\Core\Inc`（CubeMX 生成的工程默认就有）

编译一下，应该能过。

---

## 第三步：`main.c` 里加 3 处

⚠️ **一定要写在 `USER CODE BEGIN / END` 之间**，否则 CubeMX 重新生成代码时会被删掉。

```c
/* USER CODE BEGIN Includes */
#include "hc05.h"
/* USER CODE END Includes */
```

```c
  /* USER CODE BEGIN 2 */
  HC05_Init(&huart1);          /* 初始化蓝牙 */
  /* USER CODE END 2 */
```

```c
  /* USER CODE BEGIN WHILE */
  while (1)
  {
    HC05_Poll();               /* 一直调，它自己收命令并执行 */
    /* USER CODE END WHILE */

    /* USER CODE BEGIN 3 */
  }
  /* USER CODE END 3 */
```

> ⚠️ `while(1)` 里**不要放 `HAL_Delay()`**，放了之后自动停车会失效、命令响应也变慢。
> 需要延时就用 `HAL_GetTick()` 自己算。

## 第四步：把电机代码接进去

打开 `hc05.c`，找到这个函数（大概在文件中间，有很明显的注释）：

```c
static void Car_SetVector(int16_t vx, int16_t vy, int16_t wz)
{
  /* Mecanum_SetVector(vx, vy, wz);   ← 换成电机驱动的函数 */

  (void)vx;
  (void)vy;
  (void)wz;
}
```

**这是唯一需要你改的地方。** 三个参数：

| 参数 | 意思 |
|---|---|
| `vx` | 前后（正数前进，负数后退） |
| `vy` | 左右平移（正数往左，负数往右） |
| `wz` | 自转（正数左转，负数右转） |

### 如果麦轮解算已经封装好了

```c
static void Car_SetVector(int16_t vx, int16_t vy, int16_t wz)
{
  Mecanum_SetVector(vx, vy, wz);      /* 换成你函数的真名 */
}
```

### 如果只有 4 个电机的 PWM 函数

```c
static void Car_SetVector(int16_t vx, int16_t vy, int16_t wz)
{
  int16_t lf = vx + vy + wz;    /* 左前 */
  int16_t rf = vx - vy - wz;    /* 右前 */
  int16_t lb = vx - vy + wz;    /* 左后 */
  int16_t rb = vx + vy - wz;    /* 右后 */

  Motor_SetPWM(1, lf);          /* 换成你的电机函数 */
  Motor_SetPWM(2, rf);
  Motor_SetPWM(3, lb);
  Motor_SetPWM(4, rb);
}
```

## 手机上怎么操作

命令是**单个字母，不用换行**，收到就执行。

| 按键 | 车的动作 |
|---|---|
| `F` | 前 |
| `B` | 后 |
| `L` | 左平移 |
| `R` | 右平移 |
| `Q` | 原地左转 |
| `E` | 原地右转 |
| `S` | 停 |
| `P` | 回 `PONG`（测通不通） |

在 **Serial Bluetooth Terminal** 里，把按键设成：

- Action：`Send` 或 `Send w/o Newline`（都行）
- Data：就填一个字母，比如 `F`
- Repeat：`Infinite`，Delay：`100 ms`

按住 = 一直跑，松手 = **0.5 秒后自动停车**（防跑飞）。

## 两个必看的坑

### 1. 报错 `multiple definition of 'HAL_UART_RxCpltCallback'`

说明你工程里已经有这个函数了（比如你也用串口收别的数据）。

**解决办法二选一：**

- 删掉你原来那个，只留 `hc05.c` 里的
- 或者删掉 `hc05.c` 里的那个，把它的内容并进你自己的回调里：

```c
void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart)
{
  /* 你原来处理别的串口的代码 */

  HC05_RxCallback(huart);   /* 需要把 hc05.c 里的回调改成这种可调用的函数 */
}
```

（第二种要改代码，不确定的话直接问我。）

### 2. 用 CubeMX 重新生成代码后，蓝牙不动了

99% 是调用写在了 `USER CODE` 区外面，被覆盖掉了。
`hc05.c` 和 `hc05.h` 本身不在 CubeMX 的生成范围里，不会被覆盖，放心。

## 想改的地方

都在 `hc05.c` 开头那一段：

```c
#define SPEED      500    /* 遥控速度，按你电机 PWM 范围改 */
#define STOP_TIME  500    /* 0.5 秒没命令就停车 */
```

接收缓冲大小 `RX_MAX` 默认 64 字节，一般不用动。

## 有疑问就问

这套代码是给 STM32F103 + HAL 写的，用的是标准 HAL 接口
（`HAL_UART_Receive_IT` / `HAL_UART_Transmit`），跟你的 HAL 版本无关，能直接用。
